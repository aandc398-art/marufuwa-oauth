プライバシーポリシー

対象：OAuth アプリ「MARUFUWA 04C Make Cloud Render」（以下「本アプリ」）

利用者

本アプリは制作者本人の個人用ワークフローです。利用するのは制作者本人が管理する専用 Google アカウントだけで、第三者の利用は想定していません。

アクセスするデータ

  • Google Cloud（スコープ：cloud-platform）：制作者本人のプロジェクト内にある、特定の Cloud Storage バケットへの動画素材・成果物の保存と読み取り、および特定の Cloud Run ジョブの起動と状態確認。実際の権限は IAM でこのバケットとジョブだけに制限されています。
  • Google Cloud Storage：上記バケット内のオブジェクトの作成と読み取り。

Gmail、連絡先、カレンダー、他のプロジェクトや他の利用者のデータにはアクセスしません。

データの利用と共有

取得した認証情報とデータは、動画のレンダリングと配送のためだけに Make（自動化サービス）上で使われます。第三者への販売・共有・広告利用は行いません。認証トークンは Make の接続設定内にのみ保存されます。

保存と削除

素材と成果物は制作者本人の Google Cloud / Google Drive にのみ保存されます。アクセスは Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
